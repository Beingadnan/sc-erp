# Data Dictionary

Status: Phase 2 (implemented: migrations 0000–0002). Extended each phase.

## Conventions (all tables)

| Item             | Rule                                                                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Primary key      | `id uuid` UUIDv7, generated by the app (`newId()`) or `app.uuid_v7()`                                                                           |
| Tenant ownership | `tenant_id uuid not null` on every tenant table; first column of every index                                                                    |
| Uniqueness       | Business keys unique per tenant: `unique (tenant_id, admission_number)`                                                                         |
| Foreign keys     | Composite to other tenant tables: `(tenant_id, parent_id)`                                                                                      |
| Timestamps       | `created_at`, `updated_at timestamptz not null default now()`; trigger `app.set_updated_at()`                                                   |
| Money            | `numeric(14,2)`; `Money` (bigint paise) in TypeScript; never float                                                                              |
| Status           | `text` + `check (status in (...))` — readable, easy to extend                                                                                   |
| Text identity    | Emails `citext`; phone numbers E.164 `text`                                                                                                     |
| Soft delete      | Only where history matters (students, staff, fee heads): `archived_at timestamptz`. Financial rows are never deleted; corrections are reversals |
| Personal data    | Columns tagged `PII` or `SENSITIVE` below; never logged; masked in UI where marked                                                              |

## Migration-provided objects (0000_foundation)

| Object                                              | Purpose                                                         |
| --------------------------------------------------- | --------------------------------------------------------------- |
| `app.uuid_v7()`                                     | Time-ordered UUID default                                       |
| `app.current_tenant_id()` / `app.current_user_id()` | Read transaction-local context; NULL when unset                 |
| `app.set_updated_at()`                              | Trigger function for `updated_at`                               |
| `app.enable_tenant_rls(regclass)`                   | ENABLE + FORCE RLS and create the `tenant_isolation` policy     |
| role `erp_app`                                      | Application role (NOBYPASSRLS, DML only via default privileges) |

## Phase 2 — platform tables

### users (global — a person may belong to several tenants)

| Column            | Type             | Notes                                     |
| ----------------- | ---------------- | ----------------------------------------- |
| id                | uuid PK          |                                           |
| email             | citext unique    | PII                                       |
| phone             | text null        | PII, E.164                                |
| full_name         | text             | PII                                       |
| password_hash     | text null        | Argon2id; null for OTP-only guardians     |
| email_verified_at | timestamptz null |                                           |
| mfa_secret        | text null        | SENSITIVE, encrypted at application level |
| status            | text             | `active`, `locked`, `disabled`            |
| last_login_at     | timestamptz null |                                           |

### tenants (global registry)

| Column           | Type        | Notes                                    |
| ---------------- | ----------- | ---------------------------------------- |
| id               | uuid PK     |                                          |
| slug             | text unique | subdomain; lowercase, 3–40 chars         |
| name             | text        |                                          |
| status           | text        | `trial`, `active`, `suspended`, `closed` |
| plan             | text        |                                          |
| default_timezone | text        | default `Asia/Kolkata`                   |
| default_currency | text        | default `INR`                            |

### tenant_memberships (tenant)

| Column        | Type                 | Notes                            |
| ------------- | -------------------- | -------------------------------- |
| id, tenant_id | uuid                 |                                  |
| user_id       | uuid FK users        |                                  |
| status        | text                 | `invited`, `active`, `suspended` |
| unique        | (tenant_id, user_id) |                                  |

### campuses (tenant)

| Column                | Type      | Notes                     |
| --------------------- | --------- | ------------------------- |
| code                  | text      | unique (tenant_id, code)  |
| name                  | text      |                           |
| board                 | text      | `CBSE`, `RBSE`, `ICSE`, … |
| udise_code            | text null | 11-digit UDISE code       |
| address, phone, email |           |                           |
| timezone              | text      | inherits tenant default   |

### roles, permissions, role_permissions, membership_roles

- `permissions` (global catalogue, seeded): `key` e.g. `fees.collect`, `module`, `description`.
- `roles` (tenant): `key`, `name`, `is_system` (system roles cannot be deleted).
- `role_permissions` (tenant): (tenant_id, role_id, permission_key).
- `membership_roles` (tenant): (membership_id, role_id, campus_id null = all campuses).

### sessions (global, keyed by user)

`id`, `user_id`, `token_hash` (SHA-256 of the 256-bit cookie token — the token itself is never
stored), `csrf_hash`, `active_tenant_id`, `mfa_pending`, `created_at`, `last_seen_at`,
`expires_at`, `revoked_at`, `ip`, `user_agent`.

### auth_tokens (global, function-only)

`user_id`, `tenant_ref` (invites only), `purpose` (`verify_email`, `reset_password`, `invite`),
`token_hash`, `expires_at`, `consumed_at`. Single use; a new token of the same purpose cancels
older ones.

### user_memberships_index, outbox_pending_tenants (global, trigger-maintained)

Let definer functions list a user's schools and the relay find schools with pending events
without reading across tenants (ADR-006).

### audit_logs (tenant, append-only)

`actor_user_id`, `actor_type` (`user`, `system`, `platform_support`), `action`, `entity`,
`entity_id`, `campus_id`, `diff jsonb` (PII redacted), `request_id`, `ip`, `created_at`.
No UPDATE/DELETE privileges for `erp_app`.

### outbox_events (tenant)

`event_type`, `payload jsonb`, `created_at`, `dispatched_at`, `attempts`. Written in the same
transaction as the change; relayed to BullMQ by the worker.
