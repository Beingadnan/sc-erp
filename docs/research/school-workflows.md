# School Workflows (as practised, not as featured)

Status: Phase 0 draft · Validate each flow with 2–3 pilot schools.

## Academic calendar backbone

- Indian academic year usually runs **April → March** (some state boards and schools in J&K/hilly regions differ; keep configurable).
- Key dates: admissions (Dec–Apr), session start (Apr), UDISE+ data collection (Sep–Nov, "as on" a reference date), half-yearly exams (Sep–Oct), annual exams (Feb–Mar), results + promotion (Mar–Apr).

## 1. Admission

1. Inquiry (walk-in, phone, website form) → logged as a lead with source.
2. Counsellor follow-up; school visit.
3. Application form (paper or online) with documents: birth certificate, photos, Aadhaar (optional, never mandatory for admission), previous school TC + report card, PEN/APAAR ID if transferring.
4. Interaction/entrance test for some classes.
5. Approval / waitlist / rejection; seat allotment respects class capacity and quotas (e.g. RTE 25% in private unaided schools under the RTE Act — state-run process; we only record it).
6. Admission fee payment → admission number issued → class + section + roll number assigned.
7. Student record pushed to UDISE+ (manually by school; we export).

## 2. Daily attendance

- Class teacher marks once in the morning (most schools) or per period (some senior classes).
- Absentees' parents get SMS/app alert by mid-morning.
- Late arrivals noted; half-day for leaving early.
- Corrections happen same day by teacher; later corrections by admin with reason.
- Monthly register printed/exported for inspection.

## 3. Fees (the most important daily workflow)

1. Before session: accountant defines fee heads and class-wise structures, installment plan (monthly/quarterly/termly), due dates, late fine rule, concessions (sibling, staff ward, merit, RTE, management discretion).
2. Demand generated per installment per student.
3. Collection channels: counter (cash, cheque, DD, UPI QR, card swipe), online (gateway), bank transfer/NEFT.
4. Receipt printed instantly; receipt numbers continuous per series.
5. Cheque lifecycle: received → deposited → cleared / bounced (reverse + bounce charge).
6. End of day: cashier closes counter, cash handed over, day book matched.
7. Defaulter lists → reminders → sometimes report-card / exam-hall-ticket holds (policy, configurable; flag ethically sensitive).
8. Refunds (withdrawal, excess payment) need approval; caution-money/security deposit returned on TC.
9. Audit: annual audit wants head-wise, date-wise collections and concessions granted.

## 4. Examinations and report cards

1. Assessment scheme set by board (e.g. CBSE: periodic tests + term exams + internal assessment; co-scholastic grades).
2. Exam schedule published; hall tickets for some.
3. Teachers enter marks per subject; class teacher compiles; exam in-charge verifies.
4. Principal approves; results locked and published; report cards printed/sent.
5. Promotion decisions (pass / detained / promoted with condition).

## 5. Student lifecycle events

- Section change mid-year, campus transfer within group, withdrawal with TC, re-admission, alumni.
- TC requires "no dues" clearance from accounts, library, transport.

## 6. Staff

- Joining paperwork, assignment of class teacher + subjects, leave (CL/SL/EL), substitutions when teachers are absent, monthly salary with PF/ESI/PT where applicable.

## 7. Communication

- Circulars to all/class/section, emergency closures (rain/strike), PTM invitations, fee reminders, birthday wishes (optional). WhatsApp is the de-facto channel; SMS for critical alerts.

## Pain points we heard repeatedly in market material

- Fee receipts and ledgers that don't reconcile with the bank.
- Report card formats needing vendor changes each year.
- Parents installing an app that only shows notices.
- Re-entering the same student data into UDISE+.
